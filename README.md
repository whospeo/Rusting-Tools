

# 🛠️ Rusting Tools

A Fabric mod for Minecraft that adds realistic tool oxidation and rusting mechanics.

---

## 📖 About
Rusting Tools introduces a durability and environmental mechanic where metal tools (pickaxes, swords, axes, shovels, hoes) gradually rust over time, altering their performance and durability.

### 🌟 Features
* **Oxidation Over Time:** Iron and metal tools oxidize when exposed to weather conditions like rain or thunders.
* **Degraded Performance:** Rusted tools lose efficiency and attack damage as oxidation increases.
* **Maintenance Mechanics:** Clean or polish your tools using Sandpaper block to prevent total degradation.

---

## 🎮 Requirements
* **Minecraft Version:** 26.1+
* **Mod Loader:** Fabric Loader (0.19.3+)
* **Dependencies:**
    * [Fabric API](https://modrinth.com/mod/fabric-api)

---

## 🚀 Installation
1. Download and install **Fabric Loader**.
2. Download **Fabric API** and place it in your `.minecraft/mods` folder.
3. Download the latest release of **Rusting Tools** and put the `.jar` file into your `.minecraft/mods` folder.
4. Launch Minecraft and enjoy!
